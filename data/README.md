# Данные сайта

Весь контент лежит здесь, код трогать не нужно. После правки запустите `npm run validate`: скрипт проверит файлы и подскажет, где ошибка. Та же проверка запускается перед каждой сборкой, поэтому сломанные данные не попадут на сайт.

| Файл | Что внутри |
|---|---|
| `epochs.json` | эпохи на шкале |
| `events.json` | события (точки на карте) |
| `polities.geojson` | зоны влияния государств (приблизительные полигоны) |
| `places.json` | города, крепости, сёла |
| `sources.json` | список литературы |
| `glossary.json` | пояснения терминов и народов («аланы — предки осетин») |

## Общие правила

- **Годы** — целые числа. До нашей эры — отрицательные: `-300` = 300 г. до н. э. Нулевого года нет.
- **Координаты** — `[долгота, широта]` (сначала восток, потом север), как в GeoJSON. Дербент: `[48.289, 42.058]`. Удобно брать с [geojson.io](https://geojson.io) или из Википедии (в ней порядок обратный — не перепутайте).
- **id** — латиница в нижнем регистре, цифры и дефис: `andalal-1741`.

## events.json — событие

```json
{
  "id": "andalal-1741",
  "title": "Разгром Надир-шаха в Андалале",
  "start": { "year": 1741, "month": 9 },
  "end": null,
  "datePrecision": "month",
  "dateNote": "Точные даты сражений в источниках расходятся.",
  "place": "Андалал (район Согратля)",
  "coords": [46.937, 42.262],
  "epoch": "empires",
  "summary": "3–5 коротких предложений простым языком.",
  "whyImportant": "Одна строка: почему это важно.",
  "related": [
    { "id": "gunib-1859", "relation": "ledTo" }
  ],
  "image": null,
  "sources": [
    { "id": "istoriya-dagestana-2004", "pages": "т. 1, с. 380–384" }
  ],
  "verified": false,
  "evidence": []
}
```

| Поле | Обязательно | Описание |
|---|---|---|
| `start` / `end` | `start` — да | `{ "year": 1741, "month": 9, "day": 12 }`; месяц и день можно не указывать. `end` — для событий-периодов |
| `datePrecision` | да | `day`, `month`, `year`, `decade` (1740-е), `century` (XVIII в.), `approx` (около …) |
| `dateNote` | нет | оговорка: «по разным данным…», «по старому стилю…» |
| `epoch` | да | `id` из `epochs.json` |
| `related` | нет | `relation`: `before` — «До этого», `ledTo` — «К чему привело». При клике карта и шкала переносятся к связанному событию |
| `image` | нет | см. ниже; `null` — в карточке будет заглушка |
| `sources` | желательно | ссылки на `sources.json` со страницами или разделом |
| `verified` | да | см. «Правило проверки» |
| `evidence` | для `verified: true` | `[{ "source": "id", "pages": "с. 113", "section": "гл. 3", "quote": "дословный фрагмент" }]` |

### Правило проверки

`"verified": true` ставится **только** если:

1. у события есть `evidence` с **дословной** цитатой из источника, где этот факт указан;
2. у источника в `sources.json` есть ссылка `url` на оцифрованный текст;
3. страница или раздел указаны, если они известны.

Цитаты и страницы не выдумываем. Факт «из головы» или только из Википедии получает `"verified": false`, и в интерфейсе он помечается как «требует проверки».

### Изображение

```json
"image": {
  "file": "images/events/gunib-1859.webp",
  "imageType": "real",
  "caption": "А. Д. Кившенко. Шамиль перед князем Барятинским (1880)",
  "author": "Кившенко, Алексей Данилович",
  "license": "Public domain",
  "licenseUrl": "https://…",
  "sourceUrl": "https://commons.wikimedia.org/wiki/File:…"
}
```

- `imageType`: `real` — подлинное изображение (картина, фото, гравюра); `reconstruction` — художественная реконструкция (на картинке будет такая пометка).
- Файлы лежат в `public/images/events/`. Только Wikimedia Commons и только свободные лицензии (PD, CC0, CC BY, CC BY-SA).
- Проще всего добавлять изображение командой, которая сама скачает, сожмёт файл и заполнит автора и лицензию:

```bash
npm run add-image -- "File:Имя файла на Commons.jpg" andalal-1741 "Подпись к картинке"
```

## epochs.json — эпоха

```json
{ "id": "empires", "title": "Персия, Османы и Россия", "start": 1720, "end": 1813,
  "color": "#9a5650", "summary": "Одна-две строки.",
  "periodization": { "id": "istoriya-dagestana-2004", "section": "т. 1, ч. III" } }
```

`periodization` — из какого издания взяты рамки эпохи. Эпохи идут подряд и не перекрываются.

## polities.geojson — зоны влияния

Обычный GeoJSON `FeatureCollection` с полигонами. Свойства каждого полигона:

```json
{ "polityId": "imamate", "name": "Имамат Шамиля", "start": 1834, "end": 1859,
  "color": "#3f8f6f", "note": "Территория менялась; показан примерный максимум 1840-х.",
  "labelAt": [46.1, 42.75], "sources": [{ "id": "…" }] }
```

- У одного государства может быть несколько полигонов на разные годы («снимки» территории), с одинаковым `polityId` и разными `start`/`end`.
- Полигоны можно рисовать на [geojson.io](https://geojson.io) и вставлять сюда. Заходить в море не страшно: вода рисуется поверх зон.
- Все границы на сайте подписаны как примерные.

## places.json — города и крепости

```json
{ "id": "kizlyar", "name": "Кизляр", "altNames": [], "type": "fortress",
  "coords": [46.713, 43.847], "start": 1735, "end": null, "approx": false, "note": "…" }
```

`type`: `city`, `fortress`, `settlement`, `monument`. `end: null` — существует до сих пор. `approx: true` — годы условные.

## sources.json — источники

```json
{ "id": "istoriya-dagestana-2004", "author": "ИИАЭ ДНЦ РАН",
  "title": "История Дагестана с древнейших времён до наших дней. В 2 т.",
  "year": "2004", "type": "collective", "url": "https://…", "note": "…" }
```

`type`: `collective` (коллективный труд), `monograph`, `primary` (первоисточник), `article`, `reference`, `web`.

## glossary.json — пояснения терминов

Первое упоминание термина в карточке подчёркивается; по нажатию открывается пояснение.

```json
{ "id": "alans", "term": "Аланы", "match": ["алан"],
  "text": "Ираноязычные кочевники… Их язык — предок осетинского…",
  "sources": [{ "id": "istoriya-dagestana-2004" }],
  "evidence": [{ "source": "istoriya-dagestana-2004", "pages": "т. I, с. 188", "quote": "осетинский (аланский и асский)" }] }
```

- `match` — начала слов (регулярные выражения без учёта регистра). Для коротких основ указывайте окончания и конец слова: `"лек(и|ов|ам|ами)(?!\\p{L})"` — иначе совпадёт «лекарство».
- `evidence` обязателен: пояснение должно опираться на источник, как и событие.
